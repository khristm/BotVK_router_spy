
Бот ВК для отслеживания активных устройств на роутерах EasyWRT (SNMP)

Проект предназначен для мониторинга подключенных устройств на роутерах под управлением EasyWRT с помощью протокола SNMP.

🖥️ Проверено на роутерах:

• SNR-CPE-ME2-Lite
• SNR-CPE-AX2

✨ Возможности бота:

• Получение актуального списка устройств, находящихся в сети (online).
• Мониторинг подключения и отключения клиентов с заданным временным интервалом.
• Включение и отключение режима уведомлений (слежения) прямо через меню бота.

📜 Поддерживаемые команды:

• роутер или роутеры — выбрать роутер для запроса данных о клиентах online.
• слежение — включить или отключить уведомления в чат об изменении статуса активности клиентов.
• инфо — информация о принципе работы бота.


🛠️ Инструкция по установке и настройке


Шаг 1. Предварительная настройка роутера

1. Подключитесь к роутеру по SSH.
2. Откройте файл bash snmp EasyWRT.txt, перейдите на 6-ю строку и замените your_community_string на 
вашу секретную строку (пароль) community.
3. Скопируйте весь текст из файла bash snmp EasyWRT.txt, вставьте его в терминал с открытой SSH-сессией 
и выполните команду.

Шаг 2. Настройка и запуск бота

1. Заполните файл .env.example своими данными и переименуйте его в .env.
2. Заполните файл users.yml, строго соблюдая структуру (кавычки для MAC-адресов и ID пользователей обязательны).
3. Запустите бота:
    • Вариант А: Запустите готовый файл bot.exe (скачать в Releases)
    • Вариант Б (через Python):bash
        pip install -r requirements.txt
        python main.py
